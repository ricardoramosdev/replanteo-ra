# Replanteo RA

App web para replantear planos (DXF) en el terreno con realidad aumentada fija al piso, alineando el dibujo con dos puntos de referencia.

- **App:** https://ricardoramosdev.github.io/replanteo-ra/
- **Android:** Chrome con ARCore (WebXR).
- **iPhone:** Safari con el motor 8th Wall (se descarga al entrar en RA).
- `bases_ejemplo.dxf`: plano de prueba con 9 bases.

El motor 8th Wall © Niantic Spatial, Inc. se usa bajo su [licencia de uso limitado](https://github.com/8thwall/engine/blob/main/LICENSE).
